Cómo funciona

  • El token dura 2 horas y se renueva dos minutos antes de vencer.
  • Si vence con el panel abierto, se restaura solo con el dispositivo de confianza.
  • Cerrar sesión revoca la confianza: la próxima entrada pide los 3 pasos.
  • Los cierres normales de pestaña no revocan nada.
